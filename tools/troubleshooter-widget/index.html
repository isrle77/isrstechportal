Questions

Do I need a server or a monthly subscription?

No. The widget is a single JavaScript file plus your tree file. You host them with the rest of your site, and there are no monthly fees or accounts.

Will it work on WordPress, Shopify, Wix or Squarespace?

Yes. Anywhere you can paste HTML or custom code. The editor can generate a self-contained snippet that needs no file uploads, which suits site builders that do not let you upload JavaScript files.

Does it support Hebrew, Arabic and other languages?

Yes. Write your questions in any language. Right-to-left layout switches on automatically for RTL languages, and every button text can be translated.

Will the widget clash with my theme's design?

No. It renders inside a Shadow DOM, so your site's CSS does not change it, and it does not change your site. You set its color, font, corner radius and light or dark mode.

Is it accessible?

Answers are real buttons that work with the keyboard, arrow keys and number keys. Focus moves to each new question and screen readers announce it.
