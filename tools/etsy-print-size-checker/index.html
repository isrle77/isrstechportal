A practical guide to print sizes for Etsy wall art

When you sell printable wall art, the buyer does the printing. That means your file has to work at whatever size they choose, on whatever printer or print shop they use. Two numbers decide whether that goes well: the pixel dimensions of your file and its aspect ratio. This guide explains both and shows how to set up listing files that print cleanly.

Pixels, inches, and DPI

DPI (dots per inch, often used interchangeably with PPI, pixels per inch) describes how many image pixels are packed into each inch of paper. The relationship is simple:

Print size in inches = pixels ÷ DPI

A file that is 3000 pixels wide prints 10 inches wide at 300 DPI, or 20 inches wide at 150 DPI. The pixels stay the same; only how tightly they are packed changes. For metric sizes, multiply inches by 2.54 to get centimeters.

A common misunderstanding is that the DPI value saved in the file matters. It does not. A file labelled 72 DPI with 7200 x 10800 pixels has exactly the same printing potential as one labelled 300 DPI. Changing the label without adding pixels changes nothing, which is why this checker ignores the stored value and works only with pixel dimensions.

How much resolution is enough?

  • 300 DPI is the professional standard for prints viewed at arm's length, such as 5 x 7 or 8 x 10 frames on a desk or shelf.
  • 150 to 299 DPI is usually acceptable for larger posters. People stand further back from a 24 x 36 print, so the eye cannot resolve individual pixels as easily. Clean vector-style art holds up better than detailed photography in this range.
  • Below 150 DPI prints tend to look soft or pixelated, especially edges and text.

For example, a 3000 x 4500 pixel image reaches 250 DPI at 12 x 18 inches but only 125 DPI at 24 x 36 inches. It works well as a medium print but should not be sold as a large poster.

Aspect ratio: why one file cannot fit every frame

Aspect ratio is the proportion between width and height. Standard frame sizes come in a handful of ratios, and each ratio covers several sizes:

If an image's ratio differs from the frame's ratio, something has to give: either part of the artwork is cropped off or white borders are added. A 2:3 design printed at 8 x 10 (4:5) loses about one sixth of its height. For a minimal line drawing with lots of empty space that may be fine, but for artwork with text near the edges it can ruin the print.

Which files to include in your listing

The most reliable approach is one file per ratio, each exported at the largest size you want to support. Because every size in a ratio is just a scaled version of the same shape, the buyer can print any smaller size from the big file without losing quality. A typical set of five files looks like this:

  1. 2:3 ratio at 7200 x 10800 px, covering 4x6 up to 24x36
  2. 3:4 ratio at 5400 x 7200 px, covering 6x8 up to 18x24
  3. 4:5 ratio at 4800 x 6000 px or larger, covering 4x5 up to 16x20
  4. 11:14 ratio at 3300 x 4200 px, covering 11x14
  5. ISO ratio at 7016 x 9933 px, covering A5 up to A1 for international buyers

Etsy allows up to five files per digital listing, with a size limit per file, so this set fits neatly. Save as high-quality JPG to keep files under the limit; very large PNGs often exceed it. If a file is still too big, zip several files together or reduce the largest supported size within that ratio.

Rather than simply cropping one master file into each ratio, adjust the layout for each one. Move text and key elements so nothing important sits near an edge that gets trimmed.

How to use this checker

  1. Upload your final export, or switch to Enter pixels and type the width and height.
  2. Check the maximum print size at 300 DPI and 150 DPI to see the realistic size range.
  3. Look at the group that matches your ratio. Every size there should show Pass for the sizes you plan to advertise.
  4. For the other ratios, the Ratio fit column shows how much would be cropped. Use it to decide which additional ratio files to create.

The effective DPI shown for each size assumes the image fills the entire print and any overflow is cropped, which is how most print shops handle full-bleed prints. It is calculated as the smaller of image width ÷ print width and image height ÷ print height.

Tips before you publish

  • Start large. Create artwork at the final pixel size of your biggest print instead of upscaling later.
  • Describe sizes clearly in the listing, including which file covers which frame, and mention that frames are not included.
  • Order a test print of at least one size to confirm colors and sharpness.
  • Remind buyers that home printers often cannot print edge to edge, so a small white margin may appear.

Frequently asked questions

What DPI do I need for Etsy printable wall art?

Aim for 300 DPI at the largest size you advertise. That is the standard print shops and home printers expect for sharp results viewed up close. For large posters that are viewed from a distance, 150 to 200 DPI usually still looks good, but anything below 150 DPI is likely to look soft.

Does changing the DPI setting in Photoshop make my image sharper?

No. The DPI value stored in a file is only a label. What matters is the number of pixels. A 2400 x 3000 pixel image prints at 300 DPI on 8 x 10 inches whether its metadata says 72 or 300. To print larger at the same quality you need more pixels, ideally by creating the artwork at a high resolution from the start.

How many pixels do I need for a 24 x 36 inch print?

At 300 DPI you need 7200 x 10800 pixels (24 x 300 by 36 x 300). At 150 DPI you need 3600 x 5400 pixels.

Which files should I include in an Etsy printable listing?

A common setup is one high-resolution file per aspect ratio: 2:3, 3:4, 4:5, 11:14, and ISO (A-series). Each file covers every smaller size in the same ratio, so five files can serve more than twenty frame sizes, which fits within Etsy's limit of five files per digital listing.

Why does my 8 x 10 print look cropped?

8 x 10 is a 4:5 ratio, while many artworks are designed at 2:3 (for example 24 x 36). Printing a 2:3 image at 8 x 10 means part of the image is cut off. Including a separate 4:5 file in your listing avoids this.

Is my image uploaded when I use this checker?

No. The checker reads the image dimensions inside your browser. The file never leaves your device, and nothing is sent to a server.
